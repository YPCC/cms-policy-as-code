# Graph Agent Specification

## Purpose

Design and maintain the Neo4j property-graph schema, versioning model, and provenance patterns.

## Inputs

- LinkML schema
- ADRs (especially hybrid ontology decision)
- Sample Cypher in `schemas/cypher/`

## Expected Outputs

- Cypher constraints and indexes
- Load patterns for new policy versions
- Subgraph retrieval queries for claim evaluation
- Provenance property conventions
